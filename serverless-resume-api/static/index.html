Serverless Architecture & Infrastructure as Code (IaC)

End-to-end request flow through API Gateway, Usage Plan Throttling, Lambda, and DynamoDB.

1. Client / Consumer

HTTP GET Request

Client includes x-api-key header to authenticate against the REST API.

2. API Gateway

Usage Plan & Throttle

Enforces Rate Limit (10 req/s), Burst (20 req), and Quota (5k req/mo). Rejects unauthorized calls with 403.

3. AWS Lambda

Serverless Routing

Parses path (/personal, /experience, etc.), queries DynamoDB, adds CORS headers.

4. Amazon DynamoDB

NoSQL Data Store

Fast single-digit millisecond query by section partition key and ID sort key.
